# ✊ HandControlled-Arkanoid

A brand new Arkanoid / Breakout experience played by tracking your hand movements via webcam! Put the keyboard and mouse aside; just make a fist to control your paddle. 

This project combines computer vision algorithms with classic arcade game mechanics to deliver an interactive and fun gaming experience.

## ✨ Features

*   **Real-Time Hand Tracking:** Smooth, low-latency hand detection using your webcam.
*   **Fist Control Mechanism:** Keep your hand open to leave the paddle stationary; make a fist to lock onto the paddle and move it across the screen.
*   **Classic Arkanoid Mechanics:** Breakable bricks, a bouncing ball, and a scoring system.
*   **Visual Feedback:** Real-time camera feed overlay to help you position your hand perfectly.

## 🚀 Installation & Usage

To run this project on your local machine, follow the steps below. Make sure your webcam is connected and working properly.

1.  Clone this repository:
    ```bash
    git clone [https://github.com/Ancre4sable/HandControlled-Arkanoid.git](https://github.com/Ancre4sable/HandControlled-Arkanoid.git)
    ```
2.  Navigate to the project directory:
    ```bash
    cd Arkonoid
    ```
3.  Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```
4.  Run the game:
    ```bash
    python webcam_arkanoid.py
    ```

## 🎮 How to Play

1. Launch the game; a window will open showing your webcam feed.
2. Hold your hand up in front of the camera.
3. Make a **fist** to grab control of the paddle, and move your fist left or right to slide it.
4. Open your hand to stop moving the paddle.
5. Break all the bricks without letting the ball fall. Have fun!
